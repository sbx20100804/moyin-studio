墨隐 · Novel Studio 0.5.0
====================================

两个文件，任选其一：

1) Moyin-Setup-0.5.0.exe —— 安装版
   双击安装，按提示完成即可。安装到当前用户目录，不需要管理员权限。
   安装后在开始菜单搜索「墨隐」启动。

2) Moyin-Portable-0.5.0.exe —— 免安装版
   双击即可运行，数据默认存放在：
   %APPDATA%\com.moyin.novelstudio\moyin.db
   想随身携带（U 盘 / 移动硬盘）时，可先设置环境变量：
   set MOYIN_DATA_DIR=你的目录
   再启动，作品与密钥都会存在该目录下。

第一次打开
------------------------------------
· 自带一个示例作品，可以直接体验。
· 点右上角齿轮（或 Ctrl + ,）打开设置 → 模型：
    Base URL   https://api.deepseek.com
    API Key    你的密钥
    模型       deepseek-chat
  点「测试连接」确认，再点「保存」。
· 光标放到正文结尾，点右侧「续写本章」或「写完本章」。

快捷键
------------------------------------
Ctrl + K        命令面板
Ctrl + F        全文搜索 / 替换
Ctrl + Enter    从光标处续写（光标在文末就接最后一句）
Ctrl + S        保存（平时会自动保存）
Ctrl + N        新建章节
Ctrl + J        收起 / 展开 AI 面板
Ctrl + Shift + F 专注模式
Ctrl + ,        设置

新版要点（0.5.0）
------------------------------------
【新增】
· 「写完本章」：按作品的「每章字数」把这一章补满再收尾，不再只挤几百字。
  它会算清「已写多少、还差多少」，并按缺口放宽输出上限，不受模型默认 max_tokens 限制。
· 「整章重写」：整章换写法、情节不动；替换前自动存快照，结果明显变短会拒绝替换，防止被截断。
· 「每章字数」独立字段：管生成；「目标字数」管全书进度条，两者互不干扰。
· 新增「言情」文风预设：关系位移、三拍结构、情绪写成可测量的距离与动作、叙述者可以撒谎。
· 题材补充改为按表匹配：选「言情」「日本校园轻小说」等会各自追加对应写法，不再只有轻小说一种。
· 三版同写单版失败会自动重试一次，不再白丢一版。

【AI 识别设定 · 重做】
· 新增准入标准：有专名 + 忘掉就会写错，才算一条设定；一次性道具、无名龙套、泛称不再入库。
· 已有设定会带上类型与身份一起给模型，能判断是不是同一个人。
· 重名条目默认「合并」，描述改为追加而不是丢弃新信息，别名与常用词取并集。
· 结果自动按 人物 → 地点 → 势力 → 物品 → 设定 排序。

【修复】
· 恢复历史版本前先保存当前稿，不再吞掉未保存的草稿。
· 历史面板跨章节切换时不再显示别的章的快照，恢复前会校验章节。
· 多候选里被取消的那一版会标「已中止」，不再当作完成参与评估。
· 保存到已被删除的章节会明确报错，不再静默成功。
· 点「停止」立即生效（约 80 毫秒），不再等下一块数据到达（最长 90 秒）。
· 修复正文框高度被压成 72 像素、正文只剩最上面几行、下面一片空白的问题。
· 保存改为单事务：正文、日更字数、作品时间戳要么一起写成功，要么都不写。

【数据】
· 数据库迁移到 v8，老库自动升级，不会丢稿。

写作建议
------------------------------------
· 先填两三个主要人物的「角色语气」，比只写身份有效得多。
· 轻小说：多写对话和动作，允许单句成段，章末留钩子。
· 言情：不要直接写情绪，写距离、时间、手上的动作。
· 语感样本比「形容词堆叠」更有效，找一段你真正想模仿的段落。
· 生成后先看「人味」分；低于 60 就点「去 AI 味」再改一遍。
· 手写章纲、伏笔台账、角色语气、语感样本，是让 AI 不跑偏的四件套。

隐私
------------------------------------
所有作品、设定都存在本机 SQLite 里，不经过任何服务器。
API Key 使用 Windows DPAPI 加密后写入数据库，明文不落盘。
只有你点击生成时，才会把当前上下文发送给你配置的模型服务。
