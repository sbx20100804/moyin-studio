墨隐 · Novel Studio 0.1.0
====================================

两个文件，任选其一：

1) 墨隐-Setup-0.1.0.exe —— 安装版
   双击安装，按提示完成即可。安装到当前用户目录，不需要管理员权限。
   安装后在开始菜单搜索「墨隐」启动。

2) 墨隐-便携版-0.1.0.exe —— 免安装版
   双击即可运行，数据默认存放在：
   %APPDATA%\com.moyin.novelstudio\moyin.db
   想随身携带（U 盘 / 移动硬盘）时，可先设置环境变量：
   set MOYIN_DATA_DIR=你的目录
   再启动，作品与密钥都会存在该目录下。

第一次打开
------------------------------------
· 自带一个示例作品《长夜将明》，可以直接体验。
· 点右上角齿轮（或 Ctrl + ,）打开设置 → 模型：
    Base URL   https://api.deepseek.com
    API Key    你的密钥
    模型       deepseek-chat
  点「测试连接」确认，再点「保存」。
· 光标放到正文结尾，点右侧「续写本章」或按 Ctrl + Enter。

快捷键
------------------------------------
Ctrl + K        命令面板
Ctrl + F        全文搜索 / 替换
Ctrl + Enter    从光标处续写（光标在文末就接最后一句）
Ctrl + S        保存（平时会自动保存）
Ctrl + N        新建章节
Ctrl + J        收起 / 展开 AI 面板
Ctrl + Shift + F 专注模式
Ctrl + ,        设置

新版要点（0.1.0）
------------------------------------
· 重写系统提示词：贴着人物写、少套语、留白；章节有章纲时按章纲走
· 续写从光标处插入；推理模型显示「思考过程」；采纳前自动快照可恢复
· 新增「线索」页：伏笔台账，待回收线索会进提示词
· 设定页可「从本章抽取」人物 / 地点 / 物件
· 全文搜索（Ctrl F），支持替换当前章
· 写作统计：14 天字数、今日、连续天数
· 旧章节关键词召回；上下文超窗口自动裁剪
· 删除章节进回收站，可恢复
· 大纲视图、三版同写、按段采纳、导入导出、提示词模板

隐私
------------------------------------
所有作品、设定都存在本机 SQLite 里，不经过任何服务器。
API Key 使用 Windows DPAPI 加密后写入数据库，明文不落盘。
只有你点击生成时，才会把当前上下文发送给你配置的模型服务。
