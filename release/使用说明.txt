墨隐 · Novel Studio 0.1.0
====================================

两个文件，任选其一：

1) 墨隐-Setup-0.1.0.exe —— 安装版
   双击安装，按提示完成即可。安装到当前用户目录，不需要管理员权限。
   安装后在开始菜单搜索「墨隐」启动。

2) 墨隐-便携版-0.1.0.exe —— 免安装版
   双击即可运行，数据默认存放在：
   %APPDATA%\com.moyin.novelstudio\moyin.db
   想随身携带（U 盘 / 移动硬盘）时，可先设置环境变量：
   set MOYIN_DATA_DIR=你的目录
   再启动，作品与密钥都会存在该目录下。

第一次打开
------------------------------------
· 自带一个示例作品《长夜将明》，可以直接体验。
· 点右上角齿轮（或 Ctrl + ,）打开设置 → 模型：
    Base URL   https://api.deepseek.com
    API Key    你的密钥
    模型       deepseek-chat
  点「测试连接」确认，再点「保存」。
· 光标放到正文结尾，点右侧「续写本章」或按 Ctrl + Enter。

快捷键
------------------------------------
Ctrl + K        命令面板
Ctrl + F        全文搜索 / 替换
Ctrl + Enter    从光标处续写（光标在文末就接最后一句）
Ctrl + S        保存（平时会自动保存）
Ctrl + N        新建章节
Ctrl + J        收起 / 展开 AI 面板
Ctrl + Shift + F 专注模式
Ctrl + ,        设置

新版要点（0.3.1）
------------------------------------
· 修复「新增」模型配置无效：现在可以正常添加多个配置
· 「测试连接」「拉取列表」改用表单当前值，改完地址/Key 不用先保存
· 模型下拉改为真正的列表：拉取后可点箭头选择，不再依赖 datalist
· 401 / 404 / 429 / 超时给出可读提示，不再直接抛一整段 JSON
· 错误提示去重并最多显示 3 条，不再铺满界面
· 「设为默认模型」会立即切换当前使用的模型
· 设置页版本号改为读取应用版本
· 角色语气库与「轻小说」对白改写（0.3.0 新增）

写作建议
------------------------------------
· 先填两三个主要人物的「角色语气」，比只写身份有效得多。
· 轻小说：多写对话和动作，允许单句成段，章末留钩子。
· 语感样本比「形容词堆叠」更有效，找一段你真正想模仿的段落。
· 生成后先看「人味」分；低于 60 就点「去 AI 味」再改一遍。
· 手写章纲、伏笔台账、角色语气、语感样本，是让 AI 不跑偏的四件套。

隐私
------------------------------------
所有作品、设定都存在本机 SQLite 里，不经过任何服务器。
API Key 使用 Windows DPAPI 加密后写入数据库，明文不落盘。
只有你点击生成时，才会把当前上下文发送给你配置的模型服务。
