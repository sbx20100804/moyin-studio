墨隐 · Novel Studio 0.4.3
====================================

两个文件，任选其一：

1) 墨隐-Setup-0.4.3.exe —— 安装版
   双击安装，按提示完成即可。安装到当前用户目录，不需要管理员权限。
   安装后在开始菜单搜索「墨隐」启动。

2) 墨隐-便携版-0.4.3.exe —— 免安装版
   双击即可运行，数据默认存放在：
   %APPDATA%\com.moyin.novelstudio\moyin.db
   想随身携带（U 盘 / 移动硬盘）时，可先设置环境变量：
   set MOYIN_DATA_DIR=你的目录
   再启动，作品与密钥都会存在该目录下。

第一次打开
------------------------------------
· 自带一个示例作品《长夜将明》，可以直接体验。
· 点右上角齿轮（或 Ctrl + ,）打开设置 → 模型：
    Base URL   https://api.deepseek.com
    API Key    你的密钥
    模型       deepseek-chat
  点「测试连接」确认，再点「保存」。
· 光标放到正文结尾，点右侧「续写本章」或按 Ctrl + Enter。

快捷键
------------------------------------
Ctrl + K        命令面板
Ctrl + F        全文搜索 / 替换
Ctrl + Enter    从光标处续写（光标在文末就接最后一句）
Ctrl + S        保存（平时会自动保存）
Ctrl + N        新建章节
Ctrl + J        收起 / 展开 AI 面板
Ctrl + Shift + F 专注模式
Ctrl + ,        设置

新版要点（0.4.3）
------------------------------------
· 轻小说细则按日轻写法重写：一人称吐槽、对话占六七成、地の文要短、日常里放具体小异常、称呼变化当事件
· 反流水账：不写起床 / 走路 / 进教室这类没有阻力的流程，禁止“先…然后…接着…”，每个动作必须有目的、阻碍或反应
· 章纲按“事件清单”处理，只挑其中一场戏展开，不再逐条翻译
· 导出 Word / Markdown / 纯文本时先选范围：全部章节、仅当前章，或手动勾选某一卷 / 某几章
· 三版同写会自动评估：标出推荐版本、每版分数和「编辑视角」理由；评估失败时用本地文风分兜底
· 轻小说转折频率收紧到 400-600 字，并要求每一场让两人的关系移动一格
· 设定库新增「AI 识别」：粘贴一段话或直接用本章正文，先预览再入库；重名可合并 / 跳过 / 新建，写入后可撤销
· 首次启动新手引导：欢迎 → 选文风 → 接模型 → 写作闭环 → 开始
· 引导里可直接选文风预设、跳转设置配模型，回来继续原步骤
· 设置 › 关于 可重新观看引导；完成后不再自动弹出
· 轻小说提示词强化：视点、对话格式、独白、节奏、反例与语感示例
· 题材选「日本校园轻小说」会追加校园场景与距离感的写作提示
· 续写任务补上【续写从这里开始 ↓】标记；空章节改为从第一段写
· 新增输出纪律：不要询问/确认/解释；系统提示词含「使用方法」会提醒
· 生成结果像说明文字时会标出，不会再让你误以为是正文
· 章节信息新增「AI 命名」：正文/摘要/章纲起 3 个候选，可改后保存
· 卷名也能 AI：按本卷章节摘要起 3 个候选
· 标题只取本章实际写到的人、事、物，不再用没出现过的意象
· 修复「新增」模型配置无效；测试连接 / 拉取列表改用表单当前值
· 模型下拉可点选；401/404/429 给出可读提示，错误提示去重

写作建议
------------------------------------
· 先填两三个主要人物的「角色语气」，比只写身份有效得多。
· 轻小说：多写对话和动作，允许单句成段，章末留钩子。
· 语感样本比「形容词堆叠」更有效，找一段你真正想模仿的段落。
· 生成后先看「人味」分；低于 60 就点「去 AI 味」再改一遍。
· 手写章纲、伏笔台账、角色语气、语感样本，是让 AI 不跑偏的四件套。

隐私
------------------------------------
所有作品、设定都存在本机 SQLite 里，不经过任何服务器。
API Key 使用 Windows DPAPI 加密后写入数据库，明文不落盘。
只有你点击生成时，才会把当前上下文发送给你配置的模型服务。
